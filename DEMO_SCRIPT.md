# SENTINEL demo script

1. Start the API and frontend.
2. Open the dashboard and confirm the API status pill.
3. Open **SOS**, capture browser location if permitted, and submit a critical incident.
4. Open **Map** to show the latest coordinates and deterministic nearest responder.
5. Turn off network access, submit another SOS, and show the local queued state in **Offline Network**.
6. Restore network access and use **Sync now** to forward the queued SOS.
7. Open **x402 Agent** to show the deterministic agent decision and the configuration-gated payment state.
8. Open **System** and use the deterministic demo reset/seed controls for a repeatable judge walkthrough.

The demo is an MVP. Browser geolocation and in-memory API state are local behavior. x402 payment requirements are real protocol-shaped responses only when configured; the demo never claims settlement without facilitator verification.
